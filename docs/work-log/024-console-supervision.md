# 콘솔 컨트롤러 자동 복원

## 배경과 결정

운영 Mac에서 새 컨트롤러를 독립 LaunchAgent로 기동하면 감시 폴더의 파일 관측이 반복 실패했다. 같은 호스트에서 웹 패널을 통해 서명·해시와 권한을 검증한 바이너리를 console 모드로 시작하자 새로운 정상 감시 주기가 연속 기록됐다. 이 모드에서 로그인·패널 재기동 뒤에도 접수 주체를 복원하는 옵션을 추가한다.

## 완료 조건

- 명시적으로 활성화된 Darwin console 모드에서만 동작한다. 같은 컨트롤러를 중복 기동하지 않고 운영자의 중지·일시정지를 유지한다.
- 기존 패널의 제어 잠금, 바이너리와 프로세스 신원 검증을 사용한다. 단독 LaunchAgent나 별도 워커의 소유권을 확인할 수 없을 때는 시작을 보류한다.
- 로컬 회귀 검사와 GitHub CI, 실제 Mac에서의 패널 재기동 및 정상 스캔 주기를 각각 확인한다.

## 검증 근거

기존 통합 배포와 합성 전사·복구 결과는 [이슈 #22의 작업 기록](022-live-integration.md)에 있다. 호스트의 비밀값·녹음 내용·운영 DB는 작업 기록에 포함하지 않는다.
